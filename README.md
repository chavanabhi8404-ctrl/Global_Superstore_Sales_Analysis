# Global Superstore Sales Analysis

### End-to-End Data Analytics Project Using Python

## 1. Project Overview

Global Superstore Sales Analysis is an end-to-end data analytics project developed using Python.

This project analyzes sales data to understand sales trends, profit patterns, customer segments, product categories, and regional business performance. It uses data cleaning, Exploratory Data Analysis (EDA), statistical analysis, and data visualization to generate meaningful business insights.

## 2. Project Domain

Data Analytics and Business Intelligence

## 3. Project Objectives

- Analyze the Sample Superstore sales dataset.
- Understand sales and profit performance.
- Identify the best-performing product categories.
- Analyze customer segments and regional performance.
- Understand the relationship between sales, profit, quantity, and discount.
- Perform Exploratory Data Analysis (EDA).

## 4. Technologies & Skills Used

- Python             :- Programming and data analysis  
- Pandas             :- Data cleaning and manipulation 
- NumPy              :- Numerical operations           
- Matplotlib         :- Creating charts and graphs     
- Seaborn            :- Statistical data visualization 
- Jupyter Notebook   :- Development environment        

Key Data Analytics Skills:

- Business Analysis
- Insight Generation

## 5. Dataset Information

Dataset Name: Sample Superstore Sales Dataset

Dataset Details:

- Total Records: 9,994
- Total Features: 21
- Key Measures: Sales and Profit

Key Attributes:
                              
 - Order Details:- Order ID, Order Date, Ship Date, Ship Mode 
 - Customer Details:- Customer ID, Customer Name, Segment        
 - Product Details:- Category, Sub-Category, Product Name       
 - Sales Information:- Sales, Quantity, Discount, Profit          
 - Location Details:- Country, City, State, Region, Postal Code  

## 6. Project Workflow

Step 1: Data Loading & Understanding

- Imported the dataset using Pandas.
- Examined dataset dimensions and data types.
- Identified numerical and categorical columns.
- Checked the statistical summary of the dataset.

Step 2: Data Cleaning & Preprocessing

- Checked missing values.
- Identified duplicate records.
- Converted Order Date and Ship Date into datetime format.
- Prepared the dataset for analysis.

Step 3: Exploratory Data Analysis (EDA)

Performed analysis using:

- Histograms
- Bar Plots
- Pie Charts
- Scatter Plots
- Box Plots
- Correlation Heatmaps

Analyzed:

- Sales distribution.
- Category-wise sales.
- Customer segment performance.
- Region-wise profit.
- Relationship between Sales and Profit.
- Relationship between Discount and Profit.
- Category-wise profit distribution.

Step 4: Data Visualization

Used Matplotlib and Seaborn to create visualizations and identify trends, patterns, relationships, and potential outliers in the sales data.

## 7. Key Business Insights (Analytics Outcome)

- Technology category generates the highest sales and profit.
- The West region contributes the highest overall profit.
- Consumer segment accounts for the largest share of sales.
- Copiers generate the highest profit among sub-categories.
- Tables show significant losses compared to other sub-categories.

## 8. Business Recommendations

- Focus on high-performing product categories to improve sales.
- Maintain customer engagement in the Consumer segment.
- Study successful business strategies in the West region.
- Review discount strategies to protect profit margins.
